# Reclaimed Pixel Dungeon

Reclaimed Pixel Dungeon is a GPLv3 fork of [Shattered Pixel Dungeon](https://shatteredpixel.com/shatteredpd/), focused on persistent roguelite progression, settlement rebuilding, rarity-driven item growth, and future homebase raid systems.

This project is based on Shattered Pixel Dungeon by [Evan Debenham](https://shatteredpixel.com/) and the original [Pixel Dungeon](https://github.com/00-Evan/pixel-dungeon-gradle) source code by [Watabou](https://watabou.itch.io/). Reclaimed Pixel Dungeon remains licensed under the GNU General Public License v3.0, matching its upstream projects. See [NOTICE.md](NOTICE.md) and [LICENSE.txt](LICENSE.txt) for legal attribution and license details.
